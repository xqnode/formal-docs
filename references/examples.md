## 10. 代码无注释 → 行旁注释

**Before**
> ```python
> size = 12
> for i in range(0, len(answer), size):
>     yield {"type": "token", "data": {"text": answer[i : i + size]}}
>     await asyncio.sleep(0.05)
> ```

**After**
> ```python
> size = 12  # 12 字一片：模拟逐字输出，仅为演示分段效果。
> for i in range(0, len(answer), size):
>     # yield 发出一段就暂停，区别于 return 一次全返回；前端因此能逐段显示。
>     yield {"type": "token", "data": {"text": answer[i : i + size]}}
>     await asyncio.sleep(0.05)  # 0.05 秒：打字机间隔，后续替换为真实输出间隔。
> ```

改动点：魔法数字注明取值原因；新语法在行旁写清与已知写法的区别，不只写在代码后的说明里。
