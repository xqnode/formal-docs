## 命令与预期输出的验证

用于 Redis、SQL、shell 等教程，补充通用的“实跑并核对结果”流程。优先沿用项目现有验证器，不把代码围栏的语言标签当作执行器选择。

### 抽取与执行分开

`scripts/extract_blocks.py` 只抽取命令及后续原始输出，不连接数据库、不调用 shell、不运行容器。显式选择输入语言，例如：

```bash
python scripts/extract_blocks.py note.md --language bash
python scripts/extract_blocks.py note.md --language sql --language bash
```

输出 JSON，保留文件、输入与输出的起始行、语言和原始块内容；无紧随的输出块时输出为 null，留给人工判断。文字说明可以出现在输入和输出围栏之间；如中间插入其他围栏，则不跨过它配对。默认输出语言为 text/txt/output。别把 text 改成未知标签来躲避检查；先确认目标渲染器支持的语言。

抽取器处理未嵌套在引用或列表容器中的围栏；容器内的块用项目 Markdown 解析器或人工抽取，不能因没有抽取结果就宣称验证完成。

执行前明确命令实际归属 Redis、MySQL、PostgreSQL、PowerShell 或其他工具。Redis 命令可以放在 bash 围栏中方便高亮，但不是可直接交给 bash 的脚本。不要由文档内容隐式选择主机、凭证或执行环境。

### 建立可清理的实验环境

- **Redis**：使用一次性容器或独立进程。独立进程可采用 `redis-server --bind 127.0.0.1 --port 6399 --save "" --appendonly no`；先确认端口空闲，指定临时工作目录，记录进程或容器身份。不能只换端口就认定隔离，更不能清空既有服务。
- **SQL**：使用一次性本机实例或专门的临时实验数据库，按项目规定的数据库和版本运行。不要连接业务库。事务回滚不等于完整隔离，例如 MySQL 的部分 DDL 会隐式提交；临时对象也必须明确清理。
- **shell**：先逐条审阅命令，在临时目录中运行，区分 Bash 与 PowerShell。临时工作目录不会阻止绝对路径删除、网络请求或环境变量中凭证的使用；这些操作仍需单独判断授权与范围。
- **在线环境**：只提交合成示例，不上传密钥、私人数据或生产日志。验证编辑区已完整替换、Run 已完成，记录平台名称、实测日期和可获得的服务版本；不凭运行成功猜测后端版本。

每个声明可独立运行的块从干净状态开始。系列中依赖前篇文件或数据的块，按正文先重建前置条件，不能依赖作者残留状态。重置动作只针对本次实验，结束后清理自己创建的实例和对象。

### 按语义比较输出

- 固定字符串、整数返回值与错误类型按约定精确对照，输入和输出分别保存；错误示例同时检查是否走到了预期失败分支。
- 保留空值、空字符串、空数组及显示空行的差别，不能用统一 trim 掩盖数据缺失；客户端显示形式与数据库返回值分别说明。
- Redis TTL 等倒计时使用合理误差，并单独检查 -1/-2。不要把负数状态值放进时间误差范围。
- Hash、集合等不保证迭代顺序时，核对成员或字段/值配对，不要求特定顺序；需要有序结果时用能保证顺序的操作。
- SQL 没有 ORDER BY 的结果不承诺行序；有序验收补充排序，无序验收按完整行比对，避免漏掉重复行。
- 时间戳、随机 ID、耗时等变化字段按格式或关系断言，不硬编码一次实跑结果。规范允许的结果与兼容实现的实际行为都要说明。

更新正文、练习、答案和排错，让结果与实跑记录对应。只有经比较通过的块才计入“已验证”；抽取成功、语法通过或官方文档核对均不等于实际执行。

### 交付中的验证记录

记录命令块数、执行器/服务实际版本、平台或环境、日期、通过项目及未验证项。安装来源、版本要求或平台行为变化时重新核对；没有版本可读时写“平台未展示版本”，不要编造编号。示意输出明确标为示例，并注明顺序或时间等可变部分。
